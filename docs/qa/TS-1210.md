## update_project region/backupRegion when regions omitted (Q15-MCP03)

Already fixed on origin/main before this ticket started (commit f584b6233, 2026-10-29; ticket evidence was 2026-10-26). `OrganizationOperations.UpdateProjectAsync` defaults `regions` from the project's current `Regions`/`Region` and keeps the supplied `region`/`backupRegion`, so a lone primary or backup region is applied, never ignored. The E2E suite covers these paths against the fake Stripe provider (`OrganizationMcpJourneyTests`, `InviteAndMemberRoleChoices…`, `RepeatedUnsupportedRoles…`, `CandidatePolicy…`), all green on main tip.
