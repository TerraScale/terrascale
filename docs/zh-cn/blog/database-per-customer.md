# Scope application data

Give each customer a separately scoped database to separate their data and access. All databases share your organization's plan allowances; see [pricing](/zh-cn/pricing). Use [authentication](/zh-cn/guides/authentication) and [limits](/zh-cn/limits) when choosing an application boundary.
