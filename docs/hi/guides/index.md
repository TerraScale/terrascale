# Practical guides

Use the [quickstart](/hi/getting-started/) to establish one working application connection, then choose the guide for the next operation. For the SQL model, see [SQL](/hi/concepts/sql).

- [SDK reference](/hi/guides/sdks) (being updated for SQL).
- [Authentication capabilities](/hi/guides/authentication-capabilities): current sign-in methods, protocol scope and unavailable flows.
- [Authentication](/hi/guides/authentication): API keys, access tokens, IP allowlists, revocation and two-factor sign-in.
- [Connect with psql and Postgres drivers](/hi/guides/postgres-clients) (being updated for SQL).
- [Use Drizzle ORM](/hi/guides/orm-drizzle), [Use Prisma ORM](/hi/guides/orm-prisma) and [Use SQLAlchemy](/hi/guides/orm-sqlalchemy) (being updated for SQL).
- [SQL over HTTP](/hi/guides/sql-http) (being updated for SQL).
- [Errors and safe retries](/hi/guides/errors): typed failures and uncertain write outcomes.
- [Indexes](/hi/guides/indexes) (being updated for SQL).
- [Full-text search](/hi/guides/full-text-search) and [Vector similarity search](/hi/guides/vector-search) (being updated for SQL).
- [Functions](/hi/guides/functions) (being updated for SQL).
- [Metrics, log drains and alerts](/hi/guides/monitoring) (being updated for SQL).
- [Backups and restore](/hi/guides/backups-and-restore) (being updated for SQL).
- [Rename a database](/hi/guides/rename-database) (being updated for SQL).
- [File storage](/hi/guides/file-storage): project files in buckets with owner, role and public read and write rules.
- [Schema migrations](/hi/guides/migrations): versioned SQL table migrations with `ts migrate`.
- [Branches](/hi/guides/branches) (being updated for SQL).
- [Dashboard usage](/hi/guides/dashboard): customer account and database workflow.
- [Connect an AI assistant with MCP](/hi/guides/mcp): sign in or use a personal access token to connect an assistant.
- [Single sign-on](/hi/guides/single-sign-on): connect your identity provider over OIDC for a verified email domain (Team and Enterprise).
- [Import an existing database](/hi/guides/import) and [Export from PostgreSQL](/hi/guides/import-postgresql) (being updated for SQL).

The [zero-configuration contract](/hi/guides/zero-configuration) explains the platform's intended operating behavior without disclosing deployment internals.
