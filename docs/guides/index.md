# Practical guides

Use the [quickstart](/getting-started/) to establish one working application connection, then choose the guide for the next operation. For the SQL model, see [SQL](/concepts/sql).

- [SDK reference](/guides/sdks) (being updated for SQL).
- [Authentication capabilities](/guides/authentication-capabilities): current sign-in methods, protocol scope and unavailable flows.
- [Authentication](/guides/authentication): API keys, access tokens, IP allowlists, revocation and two-factor sign-in.
- [Connect with psql and Postgres drivers](/guides/postgres-clients) (being updated for SQL).
- [Use Drizzle ORM](/guides/orm-drizzle), [Use Prisma ORM](/guides/orm-prisma) and [Use SQLAlchemy](/guides/orm-sqlalchemy) (being updated for SQL).
- [SQL over HTTP](/guides/sql-http) (being updated for SQL).
- [Errors and safe retries](/guides/errors): typed failures and uncertain write outcomes.
- [Indexes](/guides/indexes) (being updated for SQL).
- [Full-text search](/guides/full-text-search) and [Vector similarity search](/guides/vector-search) (being updated for SQL).
- [Functions](/guides/functions) (being updated for SQL).
- [Metrics, log drains and alerts](/guides/monitoring) (being updated for SQL).
- [Backups and restore](/guides/backups-and-restore) (being updated for SQL).
- [Rename a database](/guides/rename-database) (being updated for SQL).
- [File storage](/guides/file-storage): project files in buckets with owner, role and public read and write rules.
- [Schema migrations](/guides/migrations): versioned SQL table migrations with `ts migrate`.
- [Branches](/guides/branches) (being updated for SQL).
- [Dashboard usage](/guides/dashboard): customer account and database workflow.
- [Connect an AI assistant with MCP](/guides/mcp): sign in or use a personal access token to connect an assistant.
- [Single sign-on](/guides/single-sign-on): connect your identity provider over OIDC for a verified email domain (Team and Enterprise).
- [Import an existing database](/guides/import) and [Export from PostgreSQL](/guides/import-postgresql) (being updated for SQL).

The [zero-configuration contract](/guides/zero-configuration) explains the platform's intended operating behavior without disclosing deployment internals.
