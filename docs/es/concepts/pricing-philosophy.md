# Usage accounting

The public catalog meters operation units and storage across selected regions. Each started 4 KiB successfully read or written counts as one operation unit. Writes count once per selected region; reads count only in the serving region. Denied and failed requests are not billed.

Plan allowances are shared at the organization level. Check the [canonical pricing sheet](/es/pricing) and [limits](/es/limits) before enrollment. Pricing policy does not establish the deployed availability of a database workflow or an unqualified replication guarantee.
