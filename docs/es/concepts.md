# TerraBase concepts

TerraBase is a SQL database. Databases are scoped to your project, and an API key or access token selects what you can reach.

The [SQL](/es/concepts/sql) page covers the query interface, and [usage accounting](/es/concepts/pricing-philosophy) explains how operations and storage are metered.
