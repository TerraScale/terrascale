# Persisted collection frontier

Collection and copying-refill removal advance `_tb_gc_floor` in the same writer
transaction as their state deletions. The persisted floor never decreases, and
the reported horizon is at least that floor. Local writes mint above it.

A join into an absent key applies a deleted clear covering versions strictly below
the floor. Newer fields remain eligible; existing live records retain their state.
A fresh certified rebuild starts with floor zero and can import an old live baseline.
Copying a complete database preserves its floor alongside its states.

is unchanged for the coordinated deploy lane. Existing files require that lane's
format reset before this schema is served; no in-place migration is provided.
Certified refill adds optional digest field 5 as described in
`2026-10-22-certified-frontier.md`; ordinary replication messages stay compatible.
