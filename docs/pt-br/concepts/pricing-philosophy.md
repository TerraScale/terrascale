# Usage accounting

The public catalog meters operation units, storage across selected regions and client egress. Each started 4 KiB successfully read or written counts as one operation unit. Writes count once per selected region; reads count only in the serving region. Denied and failed requests are not billed.

Plan allowances are shared at the organization level. Check the [canonical pricing sheet](/pt-br/pricing) and [limits](/pt-br/limits) before enrollment.

Storage uses decimal GB-region-month averaged over time during the month. Client egress counts decimal outbound application response bytes and excludes replication. Subscription prices are approved, but allowances and rates remain proposed and pending review. Paid plans propose included allowances then pay-as-you-go; Free requires no card and has no automatic overages. Usage charges are not yet collected.
