# x2: typed failures — decision log

## Item 1: SqlErrors is the single message-classification home

Driver check (`src/vendor/Turso.Data.Sqlite`, read only): `SqliteException` exposes
`SqliteErrorCode`/`SqliteExtendedErrorCode`, but the fine-grained failures we classify
(no such table/column, already exists, the constraint kinds, syntax) all surface as
`SQLITE_ERROR` (rc 1) from both the native and the remote path (`SqliteCommand.ToSqliteException`);
only the message text distinguishes them. Third-party constraint: classify on the message,
in ONE place.

- `src/TerraBase/Engine/Turso/TursoStorageTransaction.Relational.cs:358-397` `Classify` is
  the deepest copy: prefix stripping, `__turso_sqlite_error__` decoding, phrase matching,
  name extraction. Target: move the whole message pipeline verbatim into
  `SqlErrors.Classify(string message, bool interrupted)` (partial static class, generated
  regexes move with it). Relational keeps only what needs the native handle
  (`EndedByFailure`, `IsPrimaryKey` via `SqlErrors.Names`, the `TursoNativeException
  StatusCode 5` check passed as `interrupted`).
- `TursoStorageTransaction.cs:240,243` commit-constraint catch: goes through new
  `SqlErrors.IsConstraintFailure` / `IsForeignKeyFailure`; thrown messages stay
  byte-identical ("FOREIGN KEY constraint failed" / "constraint failed"), so it cannot
  reuse `Classify` (which appends constraint names).
- `TursoSession.cs:87` `Busy` and `TursoReplicas.cs:986` `Locked`: both match
  "database is locked"; route through `SqlErrors.IsLocked(message)`.
- `TursoSession.cs:85` `Stopped`: `SqliteErrorCode == 9` OR contains `StoppedMessage`.
  `StoppedMessage` ("terrabase: statement stopped") is our own marker string, not a
  third-party message; the code check is already typed. Keep local, noted under
  THIRD-PARTY as an explained exception.
- `SqlErrors.Error(string)` keeps its StartsWith mapping: its inputs are TerraBase-authored
  messages (sandbox/validation), not driver messages.

Order: hierarchies first (Classify returns `SqlFailure`), then the move.
