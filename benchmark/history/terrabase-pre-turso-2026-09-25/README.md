# TerraBase custom-engine history before the Turso pivot

This archive preserves the superseded Rust custom-engine source and selected evidence as it stood on 2026-09-25. It is historical material, not the active TerraBase or Turso implementation. No build, test, VM, or benchmark was run to create this archive. No patch in `patches/` has been applied to `source/` here.

`source/` is the exact 138-file R14 freeze from TerraBase HEAD `352d9f61185d1b685e3032519579040d169ad47d`. Its original `SOURCE-SHA256SUMS` is SHA-256 `9b4483ea61bb76b02fb122192f552cc36669c7fe835e877da2eb3ca7cacc23e2` and is copied under `provenance/r14/` with the freeze receipt and verification plan. The snapshot includes its Cargo files, Makefile, GOAL, docs, protocol, and human-maintained AGENTS.md byte-for-byte. The archive does not claim an R14 runtime pass; the R14 default product and Fast/Slow no-run builds were compile-only, and remaining gates were incomplete when the pivot cancelled runtime preparation.

`patches/accepted/` preserves the owner-identified D2 storage v5, object, and server v2 private patch artifacts plus their source manifest. “Accepted” here means accepted for preservation and narrow source scope. They were not built or runtime-verified, and this archive does not claim that applying them together has been validated. `patches/wip/d2-tests/` contains the three separate test-source candidates. `patches/wip/c4/` contains the private SQLite C4 patch and its three candidate files. These WIP artifacts were not accepted as passing tests or benchmark results.

`evidence/r12-fast/` is **actual historical R12 runtime evidence for a different frozen source**, not R14 evidence. Its guest stdout in `guest-output.tar.gz` reports **35 passed and 6 failed**; `run-manifest.json` records a failed run. The R12 artifact receipt includes compile-only results and failed or skipped lint gates. The five expiry-fixture failures and one wrong-signed-leaf failure led to later source corrections, but there is no current-source Fast pass in this archive.

`evidence/p04-provisional/` copies the original focused P04 a2 analysis, campaign protocol, and execution receipts without rewriting results. Eight measured pairs produced five **provisional TerraBase losses**; the analysis explicitly says `acceptance_qualified=false`. It is neither a full P04 matrix verdict nor a result for R14, the D2/C4 candidates, or Turso.

`payload-provenance.json` lists every copied payload's original path and SHA-256. `SHA256SUMS` checks the archived source, evidence, patches, provenance, and this README; `MANIFEST.json` records the archive identity and status. From this directory, run `sha256sum -c SHA256SUMS` and `sha256sum -c MANIFEST.SHA256` to verify the archive. The archive-local `.gitignore` keeps the exact frozen `src/bin` file and original `.tar.gz` evidence visible to Git despite broader repository ignore patterns. No large Cargo target directories, guest images, upstream Turso tree, or live benchmark results were copied or changed.
