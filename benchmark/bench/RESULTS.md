# Benchmarks

The benchmark receipts and tables under [`rust/`](rust/) are historical results
from the former Rust TerraBase implementation. They are retained as an
independent result set so they are not presented as measurements of the current
C# TerraBase host.

New C# TerraBase benchmark results belong directly under `bench/results/` and
must use an explicit implementation label in their report. The archived Rust
receipts remain byte-for-byte in [`rust/results/`](rust/results/) and the
baseline snapshot in [`rust/results-baseline-20260909/`](rust/results-baseline-20260909/).
