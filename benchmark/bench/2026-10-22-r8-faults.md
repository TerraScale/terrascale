## Scope of the fault model

| Control | Limit |
| --- | --- |
| Peer partition, delay, bandwidth cap and loss | Real peer TCP proxies; loss is seeded connection resets, not kernel packet loss or `tc` evidence. |
| Process death and restart | Actual SIGKILL of isolated child processes, retaining their data directories. |
| Slow fsync and power-loss model | Linux preload shim delays WAL syncs and records synced lengths; stopped WAL truncation is a bounded model, not a hardware power cut. Unsynced main-file/checkpoint writes and WAL-generation reuse are not fully modeled. |
| Seed replay | Reproduces workload inputs and fault parameters; OS scheduling, request completion order and concurrent random draws are not deterministic. |
| Clock skew and assertions | Node wall-clock offsets are injected; a complete passing run must still establish acknowledged data, retained tombstones, catalog/unique state and resumed feed behavior. Empty-feed calibration alone proves none of those. |
