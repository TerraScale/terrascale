# RT2 live 6-direction replication on OCI gru / sjc / fra (2026-10-23)

Replication works in every measured direction and concurrent same-document writes converge everywhere to the
LWW-by-(HLC, node) winner (0 violations in 1,339 races over both runs). Lag misses the p99 < 200 ms target in every
direction on every binary measured. On main `d9d804812` (RT2c, 10:28–11:20 Z) the sjc ↔ fra p99 is 827–906 ms idle,
2.4× RT2's 344–352 ms on `888ea413`. An interleaved A/B shows `888ea413` as slow as main on the same hosts now, so the
doubling is host contention (the production TerraBase beside each cell, load1 4–7, CPU pressure 30–80 %), not code.
gru could not be redeployed (no ssh to the VM), so the gru rows run gru on `f06647f22` and the two directions into gru
were not measured on main. Raw data stays outside the repository; see [Raw data](#raw-data).

## Runbook: redeploy a commit to the cells and re-measure

Helper scripts live outside the repository on delta in `~/.cache/rt2c-live/drive/` (`deploy.sh`, `lag.sh`, `table.py`,
`loadsum.py`, `op.sh`, `billload.sh`, `cell-unit.sh`, `vault-to-host.sh`). From the repository root at the commit:

```
export TsDotnetRoot=$HOME/Projects/TerraScale/ts-dotnet; c=$(git rev-parse --short=9 HEAD); out=~/.cache/rt2c-live/bins
nice -n 19 make terrabase-publish RUNTIME=linux-arm64 PUBLISH_DIR=$out/$c-linux-arm64
for h in ts-sjc-1 ts-fra-1; do scp $out/$c-linux-arm64/terrabase $h:rt2c/terrabase-$c &&
  ssh $h "sudo install -m 755 ~/rt2c/terrabase-$c /var/lib/terrabase-rt2/bins/$c"; done
~/.cache/rt2c-live/drive/deploy.sh $c ts-sjc-1 ts-fra-1        # switch, restart, wait for /readyz
d=~/.cache/rt2c-live/raw/$c; ~/.cache/rt2c-live/drive/lag.sh $d 5 60 xregion-probe
python3 ~/.cache/rt2c-live/drive/table.py $d; python3 ~/.cache/rt2c-live/drive/loadsum.py $d
ssh ts-sjc-1 'cd ~/rt2c && TS_BENCH_API_KEY=$(cat ~/rt2/key) ./repl-converge -targets rt2cconv.json -collection lww-x -docs 50'
```

gru needs `linux-x64` and ssh to `ubuntu@10.200.99.52` (only beta's key today); with it, `DIRS` defaults to all six
directions. `~/rt2c/cell-unit.sh tigris|r2` on a cell recreates its unit on either store. Probe and tool binaries
(`xregion-probe`, `xregion-probe-load`, `repl-converge`, `repl-bench`) sit in `~/rt2c/` on sjc and fra.
