# RT2c live replication on OCI gru / sjc / fra: 6 directions, LWW convergence, lag before and after pipelining

Live measurement on the RT2c test cells (not production) before and after per-database pipelined batches (#536 receiver
chain, #557 sender window, #568 receiver coalescing). Replication works in all six directions with no probe lost in the
after run, and concurrent same-document writes converge to the LWW-by-(HLC, node) winner in every race. Lag p50 overhead
above the network floor fell 2-5x under load. p99 < 200 ms per direction is **not met**, neither on these cells nor in
production (section "Production"): there the median sits 31-39 ms above the network floor and p99 is 244-650 ms.

Raw data (not committed): `2026-10-24-rt2c-live-raw.tar.gz`, sha256 `dd406903c77304c241a13760ea6bad61a3617be20db0c14eec85e184a4c32745`,
kept on delta in `~/.cache/rt2c-live/`.

  probes, `rt2cconv` (all regions) for convergence.
- Lag: `benchmark/cmd/xregion-probe` (#417 method): write at A, poll B every 2 ms (5 ms on gru) until it serves the write;
  latency = visible on B - t0 - RTT/2, single clock (B's). Idle: 5 runs x 60 probes per direction, directions interleaved per
  run. `-load 2`: 3 runs x 60 probes with 2 writers on the origin beside the probes (Hobby's concurrency limit is 4).
- Convergence: `benchmark/cmd/repl-converge` (#598) from ts-sjc-1: 3 repeats x 50 documents per region pair.
- Host load and CPU pressure (PSI `some`) are sampled on both ends before and after every direction and repeat; `prod_cpu`
  is the production TerraBase process's CPU on the same host.

## Reading

- **Overhead p50 above the floor:** idle 46-73 -> 31-41 ms; under `-load 2` 90-191 -> 35-75 ms. Writes no longer queue a
  round trip behind the previous batch of their database.
- **p99:** 243-448 ms after. The tails follow host contention, not replication steps: during the after run production
  TerraBase used 79-98 % of a core on sjc and fra (CPU PSI some 37-63 %), against 21-52 % in the before run; gru is a
  CPU-starved free VM. One direction is below 200 ms at its per-run p99 median under load (sjc -> fra 187.6); none at the
  pooled p99.
- **Origin ack** halved (344-489 -> 156-217 ms p50) because writes now answer after the local durable commit (#541, decision
  0013e); the probe still waits for its remote copy (`TB-Durability: remote_durable`), so that column is the opt-in path.
- **Convergence did not get slower.** `converged_ms` counts from the later write's acknowledgement; #541 moved that
  acknowledgement earlier (later ack p50 380 -> 181 ms), so the same work appears after it (177 -> 352 ms). From the PUTs to
  every region serving identical bytes: p50 558 -> 534 ms, p99 675 -> 652 ms. 0 LWW violations in 450 + 450 races.
