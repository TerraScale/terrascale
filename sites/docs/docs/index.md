TerraScale is an active-active multi-region SQL database with a Postgres wire, plus functions, file storage and live edge shapes. A database lives in any set of the three regions, and every region of the set is an equal peer that commits writes locally: fast by default, serializable on request, with read-your-writes everywhere.
