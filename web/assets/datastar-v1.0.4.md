from `starfederation/datastar` release tag `v1.0.4`, commit

https://github.com/starfederation/datastar/blob/v1.0.4/bundles/datastar.js

`727844adfc825ee651fb93c544a2a739986f9a21820a94524b35f0cac470cf91`.
