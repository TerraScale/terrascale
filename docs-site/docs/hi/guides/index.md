# Practical guides

Use the [quickstart](/hi/getting-started/) to establish one working application connection, then choose the guide for the next operation. For the SQL model, see [SQL](/hi/concepts/sql).

- [SDK reference](/hi/guides/sdks)
- [Authentication capabilities](/hi/guides/authentication-capabilities): current sign-in methods, protocol scope and unavailable flows.
- [Authentication](/hi/guides/authentication): API keys, access tokens, IP allowlists, revocation and two-factor sign-in.
- [Connect with psql and Postgres drivers](/hi/guides/postgres-clients): host, credentials, dialect and transactions for psql, node-postgres, psycopg, pgx and Npgsql.
- [SQL over HTTP](/hi/guides/sql-http): run SQL statements with any HTTP client.
- [Use Drizzle ORM](/hi/guides/orm-drizzle): run Drizzle's SQLite dialect over the JavaScript SDK.
- [Use Prisma ORM](/hi/guides/orm-prisma): run Prisma's SQLite dialect over the JavaScript SDK's driver adapter.
- [Use SQLAlchemy and Alembic](/hi/guides/orm-sqlalchemy): run SQLAlchemy's SQLite dialect, the ORM and Alembic migrations over the Python SDK.
- [Use GORM, sqlc and bun with Go](/hi/guides/orm-go): run GORM, sqlc and bun over the Go SDK's database/sql driver.
- [Use Dapper and ADO.NET with .NET](/hi/guides/orm-dotnet): run Dapper and ADO.NET over the .NET SDK's DbConnection provider.
- [Typed SQL with the Rust SDK](/hi/guides/rust-sql): queries, typed `query_as` selects, transactions over the session and batches in Rust.
- [Errors and safe retries](/hi/guides/errors): typed failures and uncertain write outcomes.
- [Indexes](/hi/guides/indexes): secondary, unique, partial and expression indexes with `CREATE INDEX`, `DROP INDEX` and `EXPLAIN QUERY PLAN`.
- [Functions](/hi/guides/functions)
- [Monitoring](/hi/guides/monitoring): usage counters, request analytics, Prometheus metrics, request logs and the status page.
- [Backups and restore](/hi/guides/backups-and-restore)
- [Rename a database](/hi/guides/rename-database): change a database's name from the dashboard, API, CLI or SDKs.
- [File storage](/hi/guides/file-storage): project files in buckets with owner, role and public read and write rules.
- [Schema migrations](/hi/guides/migrations): versioned SQL table migrations with `ts migrate`.
- [Branches](/hi/guides/branches)
- [Multi-region writes and conflicts](/hi/guides/multi-region-writes-and-conflicts): column winners, transaction states and the conflict log.
- [Dashboard usage](/hi/guides/dashboard): customer account and database workflow.
- [Connect an AI assistant with MCP](/hi/guides/mcp): sign in or use a personal access token to connect an assistant.
- [Single sign-on](/hi/guides/single-sign-on): connect your identity provider over OIDC for a verified email domain (Team and Enterprise).
- [Import data](/hi/guides/import): load rows into a database with batched SQL statements.

The [zero-configuration contract](/hi/guides/zero-configuration) explains the platform's intended operating behavior without disclosing deployment internals.
