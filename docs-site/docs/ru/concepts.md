# TerraBase concepts

TerraBase is a SQL database. Databases are scoped to your project, and an API key or access token selects what you can reach.

The [SQL](/ru/concepts/sql) page covers the query interface, and [usage accounting](/ru/concepts/pricing-philosophy) explains how operations and storage are metered.
