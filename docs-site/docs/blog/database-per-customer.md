# Scope application data

Give each customer a separately scoped database to separate their data and access. All databases share your organization's plan allowances; see [pricing](/pricing). Use [authentication](/guides/authentication) and [limits](/limits) when choosing an application boundary.

A push stream that returns NATS error 10074 is not retried, because the stream wants more replicas than the cluster has.
