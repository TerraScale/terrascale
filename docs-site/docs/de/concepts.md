# TerraBase concepts

TerraBase is a SQL database. Databases are scoped to your project, and an API key or access token selects what you can reach.

The [SQL](/de/concepts/sql) page covers the query interface, and [usage accounting](/de/concepts/pricing-philosophy) explains how operations and storage are metered.
