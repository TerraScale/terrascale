# Practical guides

Use the [quickstart](/de/getting-started/) to establish one working application connection, then choose the guide for the next operation. For the SQL model, see [SQL](/de/concepts/sql).

- [SDK reference](/de/guides/sdks) (being updated for SQL).
- [Authentication capabilities](/de/guides/authentication-capabilities): current sign-in methods, protocol scope and unavailable flows.
- [Authentication](/de/guides/authentication): API keys, access tokens, IP allowlists, revocation and two-factor sign-in.
- [Connect with psql and Postgres drivers](/de/guides/postgres-clients): host, credentials, dialect and transactions for psql, node-postgres, psycopg, pgx and Npgsql.
- [Use Drizzle ORM](/de/guides/orm-drizzle), [Use Prisma ORM](/de/guides/orm-prisma) and [Use SQLAlchemy](/de/guides/orm-sqlalchemy) (being updated for SQL).
- [SQL over HTTP](/de/guides/sql-http): run SQL statements with any HTTP client.
- [Errors and safe retries](/de/guides/errors): typed failures and uncertain write outcomes.
- [Indexes](/de/guides/indexes): secondary, unique, partial and expression indexes with `CREATE INDEX`, `DROP INDEX` and `EXPLAIN QUERY PLAN`.
- [Functions](/de/guides/functions) (being updated for SQL).
- [Monitoring](/de/guides/monitoring): usage counters, request analytics, Prometheus metrics, request logs and the status page.
- [Backups and restore](/de/guides/backups-and-restore) (being updated for SQL).
- [Rename a database](/de/guides/rename-database): change a database's name from the dashboard, API, CLI or SDKs.
- [File storage](/de/guides/file-storage): project files in buckets with owner, role and public read and write rules.
- [Schema migrations](/de/guides/migrations): versioned SQL table migrations with `ts migrate`.
- [Branches](/de/guides/branches) (being updated for SQL).
- [Multi-region writes and conflicts](/de/guides/multi-region-writes-and-conflicts): column winners, transaction states and the conflict log.
- [Dashboard usage](/de/guides/dashboard): customer account and database workflow.
- [Connect an AI assistant with MCP](/de/guides/mcp): sign in or use a personal access token to connect an assistant.
- [Single sign-on](/de/guides/single-sign-on): connect your identity provider over OIDC for a verified email domain (Team and Enterprise).
- [Import an existing database](/de/guides/import) and [Export from PostgreSQL](/de/guides/import-postgresql) (being updated for SQL).

The [zero-configuration contract](/de/guides/zero-configuration) explains the platform's intended operating behavior without disclosing deployment internals.
